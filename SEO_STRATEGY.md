## 5. Core Web Vitals & Technical Optimizations

1. **LCP (Largest Contentful Paint):** High-priority hero image with `fetchpriority="high"` and pre-calculated explicit width/height (`1000x750`).
2. **CLS (Cumulative Layout Shift):** All images have explicit aspect ratio / dimensions (`width` and `height`), CSS flexbox/grid layout prevents layout jumping. `CLS = 0.00`.
3. **INP (Interaction to Next Paint):** Lightweight native JavaScript for mobile navigation and FAQ toggles; zero heavy external libraries.
4. **Font Optimization:** `font-display: swap` applied on Google Fonts (`Outfit` & `Inter`).
5. **Mobile-First UX:** Touch targets minimum `44px x 44px`, fixed bottom bar on mobile screens with direct `tel:+917599340430` call link and WhatsApp link (`https://wa.me/917599340430`).
